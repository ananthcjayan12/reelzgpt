# ReelzGPT

ReelzGPT is an AI-powered video generation platform that creates engaging videos from YouTube content.

## Features

- Generate AI videos from YouTube content
- Process and transform video content
- Create engaging social media ready clips

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

### Docker

You can deploy ReelzGPT using Docker:

```bash
docker build -t reelzgpt .
docker run -p 3000:3000 reelzgpt
```

### Coolify

ReelzGPT is optimized for deployment on Coolify. Simply connect your repository and deploy.
