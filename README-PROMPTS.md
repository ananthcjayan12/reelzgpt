# Prompt Templates Guide

This guide explains how to use and customize the prompt templates in the YouTube Video Generator application.

## Overview

The application uses AI to generate scenes, audio, and images based on YouTube transcriptions. You can customize the prompts used for each of these processes to achieve different results.

## Scene Generation Prompts

The scene generation process uses two prompts:

1. **System Prompt**: This sets the context for how the AI should generate scenes. It defines the AI's role and the tasks it should perform.

2. **User Prompt Template**: This is the prompt that includes the transcription. Use the `{transcription}` placeholder to indicate where the YouTube transcription should be inserted.

3. **Field Descriptions**: You can customize how the AI generates narration and image prompts by editing the descriptions for these fields:
   - **Narration Description**: Guides the AI on how to create the narration text for each scene.
   - **Image Prompt Description**: Guides the AI on how to create image prompts for each scene.

### Tips for Scene Generation Prompts

- Be specific about the style of scenes you want (e.g., educational, entertaining, dramatic).
- Specify the desired length and structure of scenes.
- Include instructions about the tone and mood of the narration.
- Provide guidance on the type of image prompts to generate.
- Use field descriptions to further refine how the AI generates content.

### Examples of Field Descriptions

**Narration Description Examples:**
- "Scene narration text (max 200 words)"
- "Conversational narration text with engaging storytelling (max 150 words)"
- "Professional educational narration with clear explanations (max 180 words)"
- "Dramatic narration with emotional impact (max 120 words)"

**Image Prompt Description Examples:**
- "Detailed prompt for image generation"
- "Photorealistic image prompt with detailed scene description"
- "Artistic image prompt with emphasis on mood and atmosphere"
- "Minimalist image prompt focusing on key elements only"

## Audio Settings

You can select from different voices for the audio narration:

- **Alloy**: Neutral voice
- **Echo**: Male voice
- **Fable**: Male voice
- **Onyx**: Male voice
- **Nova**: Female voice
- **Shimmer**: Female voice

Listen to the samples to choose the voice that best fits your content.

## Image Enhancement

The image enhancement feature allows you to automatically enhance the image prompts generated by the AI.

1. **Enable/Disable**: Toggle the enhancement on or off.

2. **Enhancement Template**: Customize how the prompts are enhanced. Use the following placeholders:
   - `{prompt}`: The original image prompt
   - `{aspect_ratio}`: The aspect ratio of the video (horizontal or vertical)

### Tips for Image Enhancement

- Include specific style references (e.g., "cinematic", "photorealistic", "cartoon").
- Specify desired lighting and atmosphere.
- Include technical details like resolution or quality.
- Mention camera angles or perspectives if relevant.

## Examples

### Scene Generation System Prompt Example

```
You are a creative video script writer and scene designer. Your task is to:
1. Break down the transcription into 5-7 engaging scenes
2. Create compelling narration for each scene (max 100 words per scene)
3. Generate detailed image prompts that match the narration
4. Assign appropriate moods to each scene
5. Create an engaging YouTube title and description
6. Focus on creating a cohesive story that flows naturally
```

### Image Enhancement Template Example

```
A high-quality, detailed {aspect_ratio} image of {prompt}. Cinematic lighting, professional photography, 8k resolution, highly detailed, photorealistic style.
```

## Best Practices

1. **Test Different Prompts**: Experiment with different prompts to see what works best for your content.
2. **Be Specific**: The more specific your prompts, the better the results.
3. **Iterate**: If you don't like the results, try adjusting your prompts and generating again.
4. **Save Good Prompts**: When you find a prompt that works well, save it for future use.
5. **Customize Field Descriptions**: Adjust the field descriptions to guide the AI toward your preferred style of narration and image prompts.

## Troubleshooting

- If scenes are too long or short, adjust your system prompt to specify the desired length.
- If image prompts are not generating good images, try making them more detailed and specific.
- If the narration doesn't match your style, provide more guidance in the system prompt about the desired tone and style.
- If you need more control over the output, customize the field descriptions to be more specific about what you want.
